BBE32EP kernels Cycle Count Estimation

| Home | Cycle Count | About |

This document presents the cycle count estimation for BBE32EP library functions.

The estimation was performed by regression analysis of cycle count data points obtained by running the BBE32EP kernels on simulator.

The below table contains formulas, data plots and an online calculator for estimating function execution cycle count.
Note that the provided cycle count only takes into account the data processing time and does not include data-transfers from/to the SRAM or DDR.

As an alternative to using the online calculator in the last column, the fit formulas may be used directly (by copy / paste) in a Microsoft Excel Sheet where the input parameter values are set in the A1, B1, C1, D1, . .. cells.

Field Documentation

◆ pIn

uint32_t pIn

[in] Pointer to data buffer containing input data vector for Range*4ch. Input is ADC samples in order (CH1,CH2,CH3,CH4). The size of the buffer is (4 * N) * 2 bytes. Each element is stored on 16 bits. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pInDataAbs

uint32_t pInDataAbs

[scratch] Pointer to scratch area buffer that will hold the absolute values of the input data vector. The size of the buffer is (4 * N) * 2 bytes. Each element is stored on 16 bits. OPTIONAL: For best performance this should point to a buffer in DRAM area. IMPORTANT: Buffer can be overwritten/reused between multiple kernels or runs. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pOut

uint32_t pOut

[out] Pointer to data buffer containing output data vector for Range*4ch. Output is ADC samples in order (CH1,CH2,CH3,CH4). The size of the buffer is (4 * N) * 2 bytes. Each element is stored on 16 bits. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pTotalSum

uint32_t pTotalSum

[scratch] Pointer to scratch area buffer used for holding the sum of the absolute values for all 4 channels. The size of the buffer is N * 2 bytes. Each element is stored on 16 bits. OPTIONAL: For best performance this should point to a buffer in DRAM area. IMPORTANT: Buffer can be overwritten/reused between multiple kernels or runs. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

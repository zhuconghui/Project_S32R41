Outer product - complex single precision.

Each vector is multiplied by corresponding vector to output the outer product. First element is multiplied by all of the second vector's elements and so on. The results is a complex matrices.
a cross b = C[i,j] = a[i] * b[j] = a^T * b

Parameters
[out]pOutputResult contains a complex matrixes size MxN.
[in]pInput1First operand contains a complex vectors size M.
[in]pInput2Second operand contains a complex vectors size N.
[in]size1Number of elements of first input vector (M).
[in]size2Number of elements of second input vector (N).
Returns
void

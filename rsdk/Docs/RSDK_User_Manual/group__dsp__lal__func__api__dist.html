Squared Normalized Euclidean distance between one observation with 2 variables and multiple references - real single precision.

Compute order 2 squared Normalized Euclidean distance between one observation and multiple references of the same distribution with the inverse covariance matrix S pre-calculated and diagonal.
First input containf one observation.
Second input 8 parallel streams of references.
Third input contains pre-calculated symmetric inverse diagonal covariance matrix S stored as a vector c00, c11.
Output vector contains 8 scalar squared distances from the selected observation.

Parameters
[out]pOutputResult contains real vector size 8.
[in]pInput1First operand contains real vector size 2.
[in]pInput2Second operand contains 8 parallel real vectors size 2.
[in]pInput3Third operand contains real vector size 2.
Note
mahal2 (vector, vector, vector) = vector
v1 = obs_x, obs_y;
size(v1) = 1 x 2;
v2 = ref_x0, ref_x1, ..., ref_x7;
ref_y0, ref_y1, ..., ref_y7;
size(v2) = 8 x 2;
v3 = c00, c11; covariance diagonal
size(v3) = 2;
d1j = d((obs_x, obs_y), (ref_xj, ref_yj)) = (obs_x1-ref_xj)^2 * c00 + (obs_y1-ref_yj)^2 * c11; mahal2 (v1,v2,v3) = d11, d12, ..., d18;

Squared Normalized Euclidean distance between two vectors with 2 variables.

  • real single precision.

    Squared Normalized Euclidean distance between two vectors of the same distribution with the inverse covariance matrix S pre-calculated and diagonal.
    Input1 vector contains 8 parallel observations for 2 variables.
    Input2 vector contains 8 parallel references for 2 variables.
    Input3 contains pre-calculated symmetric inverse diagonal covariance matrix S stored as a vector c00, c11.
    Output vector contains squared distances from first to second vector.

    Parameters
    [out]pOutputResult contains real vector size 8.
    [in]pInput1First operand contains 8 parallel real vectors size 2.
    [in]pInput2Second operand contains 8 parallel real vectors size 2.
    [in]pInput3Third operand contains real vector size 2.
    Note
    mahal (vector, vector) = (vector)
    v1 = obs_x1, obs_x2, ..., obs_x8;
    obs_y1, obs_y2, ..., obs_y8;
    v2 = ref_x1, ref_x2, ..., ref_x8;
    ref_y1, ref_y2, ..., ref_y8;
    s = c00, c11; covariance diagonal
    di,j = (obs_xi-ref_xj)^2 * c00 + (obs_yi-ref_yj)^2 * c11;
    mahal (v1,v2) = d1,1, d2,2, ...., d8,8;

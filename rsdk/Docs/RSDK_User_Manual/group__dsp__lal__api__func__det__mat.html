Determinant of a matrix - complex single precision.

Function computes the determinant of a complex matrix using the upper triangular matrix resulted after the QR decomposition of the input matrix.

Parameters
[out]pOutputResult contains 8 complex scalars.
[in]pInputFirst operand contains 8 parallel complex matrices, size NxN.
[in,out]pBuffer1Scratch area contains 8 parallel complex matrices, size NxN.
It may have the same address as the input buffer - inplace mode.
In this case the input buffer is overwritten.
[in,out]pBuffer2Scratch area contains 8 parallel complex vectors, size N.
[in]sizeNumber of rows and columns in the input matrix, N.
Note
det(matrix) = scalar
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
If used in inplace mode:
size range is [2..63]
else:
size range is [2..44]

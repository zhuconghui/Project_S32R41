Convert one data stream from position k inside X parallel streams of NxM matrixes to a NxM matrix - complex single precision.

Data stream at position k is de-serialized and copied in one matrix.
The selection is done using the batch_pos index.

Parameters
[out]pOutputOutput matrix, row major format.
[in]pInputInput batch array.
[in]batch_posPosition of the extracted matrix.
[in]nrowsNumber of rows of a single matrix from the batch array.
[in]ncolsNumber of columns of a single matrix from the batch array.
[in]batch_sizeNumber of matrices saved in the batch array.

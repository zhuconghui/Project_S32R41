Detailed Description

The data types accepted by the BBE32 algos.

Parameters for Reorder algorithm.

Field Documentation

◆ doubleInBufEn

uint8_t doubleInBufEn

[in] Control flag to specify whether RsdkBbe32ReordTile16to4Ch() should toggle the pInDat pointer in a ping-pong fashion, to match with the CSI2 double-buffer data aquisition pattern. Valid values: "0" = disable, "non-0" = enable.

◆ noElements

uint16_t noElements

◆ pInDat

uint32_t pInDat

[in] Pointer to data buffer containing input data vector of 4 Channels tile 16(16 elem ch1, 16 elem ch2, 16 elem ch3, 16 elem ch4, 16 ch1, 16 ch2, 16 ch3, 16 ch4 ...) of size [noElements], containing elements on 16 bits. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pOutDat

uint32_t pOutDat

[out] Pointer to data buffer containing output data vector concatenated for all antennas, containing 16-bit elements. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

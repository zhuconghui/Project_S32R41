◆ Rsdk_SP_fillStgRadix2_Vof32cp8()

void Rsdk_SP_fillStgRadix2_Vof32cp8 ( xb_vecN_2xcf32 *  pOutput,
uint32_t  stage 
)

Fill 8 parallel identical vectors with FFT radix 2 stage twiddle factors.

  • complex single precision.

    Result contains 8 parallel identical complex vectors, size 2 to power of S, containing roots of unity often called FFT twiddle factors corresponding to a particular stage. Implemented algorithm is from the book Approximations for Digital Computers, Cecil Hastings, p140.

Parameters
[out]pOutputResult contains 8 parallel complex vectors size 2^S.
[in]stageStage number (S).
Note
fill twiddle = vector
N = 2^S
fill twiddle() = 8, cos(-2*pi* 0*1/N), sin(-2*pi* 0*1/N), ... ;
8, cos(-2*pi* 1*1/N), sin(-2*pi* 1*1/N), ... ;
8, .........................................., ... ;
8, cos(-2*pi*(N-1)*1/N), sin(-2*pi*(N-1)*1/N), ... ;
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
stage range is [2..11]

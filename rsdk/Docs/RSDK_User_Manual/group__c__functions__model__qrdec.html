QR decomposition of a matrix.

Calculate the Q and R matrix whith M=Q*R using the Householder algorithm.
Input is a matrix M[m][n].
Output R[m][n] is an upper triangular matrix.
Output Q[m][m] is a quadratic matrix.
M[m][n] = Q[m][m]* R[m][n]
m and n shall respect the following conditions:

  • m,n >= 2
  • m <= 40
  • n <= m
  • for m <= 24: n <= (m-1)
  • for 24 < m < 40: m*(2*n + m + 1) <= 1800, for example m=32 & n <= 11
  • for m = 40 -> n = 2

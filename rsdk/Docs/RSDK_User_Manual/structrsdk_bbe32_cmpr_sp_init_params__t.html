◆ pMantBwFlx

uint32_t pMantBwFlx

[in] Pointer to data buffer containing input data representing the Bit width table of size [N], containing uint8_t size elements. Each uint8 contains an 8 bit value, that can be 3/5/7/11. IMPORTANT: Set to NULL for RsdkBbe32EncCp4d, RsdkBbe32EncCp4dFmta, RsdkBbe32EncCp4dFmtb. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

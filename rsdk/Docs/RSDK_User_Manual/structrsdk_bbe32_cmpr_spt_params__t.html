uint32_t pCmprOut

[out] Pointer to data buffer containing output data vector(exponent/fill/mantissa bits) of size [P * M], containing uint8_t size elements. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pInDat

uint32_t pInDat

[in] Pointer to data buffer containing input data vector of size [N * M * 4 * 8], containing uint8_t size elements. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

◆ pMantBwFlx

uint32_t pMantBwFlx

[in] Pointer to data buffer containing input data representing the Bit width mantissa table of size [N], containing uint8_t size elements. Each uint8_t contains 2 4-bit values as 16 - MBWInput concatenated. IMPORTANT: Set to NULL for RsdkBbe32EncCp4d, RsdkBbe32EncCp4dFmta, RsdkBbe32EncCp4dFmtb. IMPORTANT: FOR RsdkBbe32EncFlxSpt34, the required values are obtained by calling RsdkBbe32CmprSptInit() with the same pointer. It is represented as uint32_t to allow passing 32-bit addresses from M7 to BBE32.

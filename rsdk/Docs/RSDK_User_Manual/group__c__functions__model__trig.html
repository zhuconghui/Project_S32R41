float const *  pInput,
uint32_t  size

Element-wise vector complex exponential of argument multiplied by PI or cispi or expj(x * PI).

Calculate the expj of all elements after scaling them up by PI.
Input is between -1 and +1.
Output is between -1 and +1 and is made out of element-wise doublets
of sin and cos applied to the input. output[k] = expj(input[k] * pi) = cos(input[k]*pi) + j * sin(input[k]*pi)

Parameters
[out]pOutputOutput vector ptr.
[in]pInputInput vector ptr.
[in]sizeNumber of elements in vector, interval [1..65535].
Returns
void
Note
expj (vector) = vector
v = n, a1, a2, ..., an;
expj (v) = n, cos(a1*pi), sin(a1*pi), cos(a2*pi), sin(a2*pi), ..., cos(an*pi), sin(an*pi);

Element-wise vector cardinal sine of argument x * PI (sin (PI*x)/(PI*x)).

Calculate the sine of all elements after scaling them up by PI.
Input is between -INF and +INF.
Output is between -1 and +1.
output[k] = sin(input[k] * pi)/(input[k] * pi)

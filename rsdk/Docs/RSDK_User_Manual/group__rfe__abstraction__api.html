Detailed Description

RFE Abstract 2.0 API is an API for radar application development. The characteristics of this API are:

  • Does not have OS dependency as it uses no OS services for accessing a message buffer (SRAM).
  • Developed and validated together with RFE-Fw to ensure compatibility with the RFE front end (TEF82XX Front End).
  • Reduces complexity of application software development by taking care of all functional configurability of HW for the customer to realize radar module.
  • Minimum set of abstract APIs for full RFE control by application.
  • Supports complex use cases, for example two chirp sequences in one radar cycle, reconfiguration of chirp profile, phase coding, timing adjustment of frame start.
  • Offer to the customer two level interface access :
    • high level access - AUTOSAR interface, the recommended level to use
    • low level access - direct access to the rfe_ like functions, which communicate with the RFE-Fw/M7-1 core

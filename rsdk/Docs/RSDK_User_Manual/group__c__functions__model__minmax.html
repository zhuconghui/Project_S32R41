Find index of Max element on vector complex elements.

Find index of Max element of all vector complex elements, by performing both absolute square value and phase analysis.

Parameters
[out]pOutputUnsigned integer scalar ptr.
[in]pInputInput vector ptr.
[in]elem_cntNumber of elements in vector.
Returns
void
Note
Find index of Max element (vector) = scalar
n = elem_cnt;
v = n, a1, a2..., an;
max (v) = index(amax);

Restrictions: j != i, j,i >= 1 and j,i <= n, ai and aj from v
Algorithm:
if (abs(ai))^2 > (abs(aj))^2, then
max(v) = i
else
if (abs(ai))^2 == (abs(aj))^2, then
if phase(ai) != phase(aj), then
// equivalent with matlab's angle() function
mav(v) = max(phase(ai), phase(aj))
else
// phases are equal too. Returns the smallest index (first found) \n
max(v) = min(i, j)
else // (abs(ai))^2 < (abs(aj))^2
max(v) = j

Inside the function's body, the maximum shall be referred to as "the extreme".

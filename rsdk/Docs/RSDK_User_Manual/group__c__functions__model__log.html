Element-wise vector ln or natural logarithm (base e).

Calculate the ln of the modulus of the input.
ln takes a real number and returns a real number. The sign of the input is ignored.
output[k] = ln(input[k])

[in]pInputInput vector ptr.

ln (v) = n, ln(a1), ln(a2), ..., ln(an);

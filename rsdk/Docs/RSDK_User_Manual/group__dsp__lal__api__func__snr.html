Element-wise signal-to-noise ratio or SNR in dB - real single precision.

Compute Signal to noise ratio of signal and noise real vectors.
output[k] = 10*log10( | input1[k]/input2[k] | )

Parameters
[out]pOutputResult real vector size N.
[in]pInput1First operand real vector size N.
[in]pInput2Second operand real vector size N.
[in]sizeNumber of elements in vector (N).
Note
signal-to-noise ratio (vector, vector) = vector
v1 = n, a1, a2, ..., an;
v2 = n, b1, b2, ..., bn;
SNR (v1,v2) = n, 10*log10(|a1/b1|),... ,10*log10(|an/bn|);
The maximum vectors' size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 2730.

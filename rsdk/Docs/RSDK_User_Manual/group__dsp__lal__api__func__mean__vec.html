Arithmetic Mean - complex single precision.

Function implements arithmetic mean operation for complex data vectors.
Output must not be in-place memory.

Parameters
[out]pOutputResult contains a pointer to 8 parallel scalar complex values.
[in]pInputFirst operand contains 8 parallel complex vectors, size N.
[in]sizeSize of input vector, N.
Note
Arithmetic mean(vector) = scalar
The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 4000.

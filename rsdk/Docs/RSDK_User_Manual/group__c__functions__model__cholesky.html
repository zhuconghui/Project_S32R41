)

Cholesky decomposition for NxN matrix - complex hermitian single precision.

Applies Cholesky decomposition on positive definite hermitian input matrix and returns upper triangular matrix with positive real values on the leading diagonal. Both the input and output matrices are assumed to be square. Size must not be smaller than 2.

Parameters
[out]pOutputOutput complex matrix ptr.

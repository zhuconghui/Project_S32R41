Eigen solver for real symmetric tri-diagonal NxN matrices using QL decomposition - real single precision.

Functions computes the eigenvalues and eigenvectors for the input matrices.
The QL decomposition is done executing Givens rotations.
A QL iteration step is performed with implicit shifts.
The function assumes the the matrices are in symmetric tri-diagonal form.
The eigen vector in column k of the matrix V has the corresponding eigenvalue in the element k of the vector D.
The eigenvector matrix pOutputV is passed to this function as the orthogonal Householder matrix used to transform an initial symmetric matrix to symmetric tri-diagonal form.
Typically only 2.5*N iterations are required but the cautious limit is 30*N.
Function is restricted to matrices with values < 1e+18 due to overflows.
Output cannot be in-place memory.

Parameters
[out]pOutputDResult contains the 8 parallel D real vectors, representing the eigenvalues - size 1xN.
[in,out]pOutputVOperand contains the 8 parallel real Householder matrix transforms - size NxN.
Result contains the 8 parallel V real matrices, representing the eigenvectors - size NxN.
[in]pInputOperand contains the 8 parallel real matrices - size NxN.
[in]iterationsMaximum number of iterations to be applied to the input matrix.
[in]sizeNumber of rows and columns of input and V matrices and D vectors: N (N>=2).
Note
eig(matrix) = vector(eigenvalues) matrix(eigenvectors)
The maximum size of N is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N < 64.

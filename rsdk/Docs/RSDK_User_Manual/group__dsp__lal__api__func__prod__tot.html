Product of all vector elements for 8 parallel streams of vectors, size N - complex single precision.

All elements in each vector are multiplied resulting a total product.

Parameters
[out]pOutputResult contains 8 complex scalars(the product of vectors' elements).
[in]pInputOperand contains 8 parallel complex vectors, size N.
[in]sizeNumber of elements in vector (N).
Note
element eprod (vector) = scalar
n = elem_cnt
v = n, a1, a2..., an;
eprod(v) = a1 * a2 * ... * an; The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 4000.

Vector complex elements reciprocal sum.

Compute reciprocal sum of multiple vector complex elements.

Parameters
[out]pOutputOutput scalar ptr.
[in]pInputInput vector ptr.
[in]sizeNumber of elements in vector.
Returns
void
Note
element reciprocal sum (vector) = scalar
n = size
v = n, a1, a2..., an;
a1 = x + iy;
ersum(v) = 1/a1 + 1/a2 + ... + 1/an;
1/a1 = x/(x^2 + y^2) - iy/(x^2 + y^2);

◆ Cte_IsrCbType

typedef void(* Cte_IsrCbType) (uint32 cteIrqReport)

Definition of callback function type to be called by the CTE interrupt handler.

This callback must be used for processing a CTE event interrupt.
Simple callback function definition example : void CallbackCte(Cte_IrqDefinitionType irqs) { ... }

Parameters
[in]cteIrqReport- a combination of Cte_IrqDefinitionType elements
Returns
nothing

◆ Cte_ModeType

enum Cte_ModeType

CTE input mode.

Defines the two possible CTE working modes : using internal CSI2 signals (Master mode) or external PAD signals (Slave mode)

Enumerator
CTE_MASTER 

CTE in Master mode. This means the timing is decided only by software control, table execution start or reset.

CTE_SLAVE_EXTERNAL 

CTE in Slave mode, table execution triggered from PADs (check IOMUX excel file for RCS_I and/or RFS_I)

CTE_SLAVE_CSI2 

CTE in Slave mode, table execution triggered by MIPI-CSI2 RFS/RCS signals.

CTE_MODE_MAX 

CTE input mode limit, not to be used

◆ Cte_OutputTypeType

enum Cte_OutputTypeType

CTE signal output types.

The possible different usage types for the CTE outputs. CTE_OUTPUT_SPT_x events can be only:

  • LOGIC and only TO_LOW or TO_HIGH states to be used.
  • TOGGLE, which will work as PULSE; only LOW and HIGH states to be used too CTE_OUTPUT_FLEX_x events can be only LOGIC and only TO_LOW or TO_HIGH states to be used.
Enumerator
CTE_OUT_HIZ 

Output type is only High-Z (if possible)

CTE_OUT_TOGGLE 

Output type is toggle, low/hi/toggle

CTE_OUT_CLOCK 

Output type is clock, low/hi/toggle with[out] sync

CTE_OUT_LOGIC 

Output type is logic, low/high/Hi-Z levels

CTE_OUT_MAX 

Output type limit (not used)

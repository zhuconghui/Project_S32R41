Upper Hessenberg reduction for NxN matrices - complex single precision.

Function reduces a complex general purpose matrix to the upper Hessenberg form using Householder
reflection or Householder transformations.
pOutputP * pOutputH * pOutputP ^T = pInput
pOutputH and pInput can point to the same address.

Parameters
[out]pOutputPResult contains 8 parallel orthogonal complex matrices, size N.
pOutputP is an unitary matrix.
[out]pOutputHResult contains 8 parallel upper Hessenberg complex matrices, size N.
They have zero entries below the first subdiagonal.
[in]pInputOperand contains 8 parallel complex matrices, size N.
[in,out]pBufferScratch area contains 8 parallel complex vectors, size N.
[in]sizeSize of input and output vectors, N >= 3.
Note
upHess (matrix) = (matrixP, matrixH)
The maximum matrix/vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 35.

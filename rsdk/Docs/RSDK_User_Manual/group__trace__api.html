◆ traceTransferCb_t

typedef void(* traceTransferCb_t) (const char *file_name, const char *src_addr, int max_bytes)

Prototype of the method used to transfer the trace buffer to PC.

The transfer function must be defined at the application level and passed as a callback argument to RsdkTraceDump().

Parameters
[in]file_nameTrace dump file name
[in]src_addrLocal memory address from where the data should be copied.
[in]max_bytesSize of the data.

◆ rsdkTraceDbgType_t

enum rsdkTraceDbgType_t

Used to indicate exactly which RSDK modules and functions are logging information related to RSDK_TRACE_EVENT_DBG_INFO.

This enum defines only the base indexes for debug events associated to the RSDK modules. Each module must define its specific debug events in its own header files, strictly within the boundaries defined here. E.g. all SPT-related debug info must be contained between RSDK_TRACE_DBG_SPT_BASE and RSDK_TRACE_DBG_LAX_BASE.

enum rsdkTraceJobType_t

◆ RsdkTraceInit()

rsdkStatus_t RsdkTraceInit ( char *  traceBuffer,
uint16_t  buffSize 
)

This function initializes the internal state of the Trace module, configures the hardware timer to count CPU cycles and resets the trace buffer.

Parameters
[in]traceBuffer- Allocated buffer for trace. Size must be equal with buffSize bytes.
[in]buffSize- Buffer size in bytes. Must be a multiple of RSDK_TRACE_LOG_ENTRY_SIZE
Precondition
It must be called after platform setup, before any call to RsdkTraceLogEvent().

◆ RsdkTraceLogEvent()

void RsdkTraceLogEvent ( rsdkTraceEventType_t  eventType,
uint16_t  extra1,
uint32_t  extra2 
)

Adds an entry to the trace log.

It constructs a log record and writes it to the global trace log buffer.

Parameters
[in]eventType- signal generic event types like function start/end, synchronization or debug info
[in]extra1- Depending on eventType, it is usually of type rsdkTraceJobType_t or rsdkTraceDbgType_t.
[in]extra2- Freeform information e.g. the instantaneous value of a program variable.
Precondition
It must only be called after RsdkTraceInit()

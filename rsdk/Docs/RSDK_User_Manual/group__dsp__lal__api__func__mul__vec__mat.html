Multiply matrices - complex single precision.

Function implements multiply operation for 2 complex data matrices.
Output must not be in-place memory.

Parameters
[out]pOutputResult contains 8 parallel complex matrices, size NxQ.
[in]pInput1First operand contains 8 parallel complex matrices, size NxM.
[in]pInput2First operand contains 8 parallel complex matrices, size MxQ.
[in]in1hRows of input matrix pInput1 and rows of output matrix pOutput, N.
[in]in1wColumns of input matrix pInput1 and rows of input matrix pInput2, M.
[in]in2wColumns of output matrix, Q.
Note
mul(matrix1,matrix2) = matrix
The following sizes are estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
in1h range is [2..N]
in1w range is [2..M]
in2w range is [2..Q]
(N * Q + N * M + M * Q) <= 4095

Multiply 8 parallel streams of NxM matrices by the transposed of the complex conjugate of 8 parallel streams of NxQ matrices - complex single precision.

All matrices from second input parallel stream are transposed and complex conjugate,
then each matrix from first input parallel stream is multiplied by corresponding matrix in second parallel stream.
Streams are independent.
Output can be in-place memory.

Parameters
[out]pOutputResult contains 8 parallel complex matrices, size NxQ.
[in]pInput1First operand contains 8 parallel complex matrices, size NxM.
[in]pInput2Second operand contains 8 parallel complex matrices, size QxM.
[in]in1hRows of the input matrix pInput1 and rows of the output matrix pOutput, N.
[in]in1wColumns of the input matrix pInput1 and columns of the transposed input matrix pInput2, M.
[in]in2wColumns of the output matrix and rows of the transposed input matrix pInput2, Q.
Note
mul(matrix1,conj(matrix2^T)) = matrix
The following sizes are estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
in1h range is [2..N]
in1w range is [2..M]
in2w range is [2..Q]
(N * Q + N * M + M * Q) <= 4095

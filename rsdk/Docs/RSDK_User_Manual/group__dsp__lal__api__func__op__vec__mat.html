Exponential - real single precision.

Function calculates the exponential of a real data vectors.
The exponential values are computed based on the identity e^x = 2^y, where y = (x / ln(2)),
which can be expanded to e^x = 2^(int)y * 2^(fractional)y.
2^y will be aproximated using Taylor series, implemented using Horner's method to reduce the number of operations.
The Taylor series approximation is expanded around the value 0.5f.
For input values < 8.5f, the function produces an approximation error < 1e-3.
For input values > 8.5f, the approximation error increases constantly with the increasing of the input values.
Output must not be in-place memory vector.

Parameters
[out]pOutputResult contains 8 parallel real vectors, representing the exponential values, size N.
[in]pInputOperand contains 8 parallel real vectors, size N.
[in]sizeSize of input and output vectors, N.
Note
exp (vector) = vector
v = (a1, a2, ..., an);
exp (v) = (e^a1, e^a2, ..., e^an);
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [1..4095]

Threshold using a real scalar to a real vector
values - real single precision.

Function perform the threshold of the real input vector
against the real scalar threshold.
Each element of the output vector is either 0 (input element < threshold )
or 1 (input element >= threshold).
One threshold is used for all 8 parallel streams.
Output must not be in-place memory vector.

Parameters
[out]pOutputResult contains 8 parallel real vectors, size N.
[in]pInput1Operand contains 8 parallel real vectors, size N.
[in]pInput2Operand contains a pointer to the real scalar threshold.
[in]sizeSize of the input and output vectors, N.
Note
thresh(vector, scalar) = vector
v = a1, a2, ... aN
s = thr
absThrsh(v, s) = (a1 >= thr), (a2 >= thr), ... (an >= thr)
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [1..4095]

Threshold using a real scalar to a complex vector
absolute values - complex single precision.

Function performs the threshold of the magnitude of the complex input vector
against the square of the scalar threshold.
Each element of the output vector is either 0 (input element < threshold^2 )
or 1 (input element >= threshold^2).
One threshold is used for all 8 parallel streams.
Output must not be in-place memory vector.

Parameters
[out]pOutputResult contains 8 parallel real vectors, size N.
[in]pInput1Operand contains 8 parallel complex vectors, size N.
[in]pInput2Operand contains a pointer to the real scalar threshold.
[in]sizeSize of the input and output vectors, N.
Note
absThrsh(vector, scalar) = vector
v = a1, a2, ... aN
s = thr
absThrsh(v, s) = (|a1|^2 >= thr^2), (|a2|^2 >= thr^2), ... (|aN|^2 >= thr^2), where |aN| is the magnitude of the complex number aN, computed as
sqrt(real(aN)^2 + imag(aN)^2)
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [1..2730]

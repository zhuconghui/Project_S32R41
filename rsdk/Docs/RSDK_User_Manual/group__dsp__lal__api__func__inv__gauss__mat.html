Matrix inverse - complex single precision.

Function implements matrix inverse using Gaussian Elimination with column pivoting.
Function assumes input matrix is non-singular and has inverse.
Output can be in-place memory.

Parameters
[out]pOutputResult contains 8 parallel complex matrices,size NxN
[in,out]pInputOperand contains 8 parallel complex matrices, size NxN.
[in]sizeNumber of rows and columns in the input and output matrices, N(>=2).
Note
inv(matrix) = matrix
Function modifies input matrix. If one needs them for ulterior processing, they should copy the input to another buffer before calling this function. The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 35.

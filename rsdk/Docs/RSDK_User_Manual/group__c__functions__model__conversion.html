Convert a complex fixed-point input vector to a complex floating point (single precision) output vector.

The input vector's fixed-point elements (their real and imaginary parts), represented as 16-bit integers, are converted to 32-bit floating point elements. The conversion causes no precision loss.

[out]pOutputOutput complex vector ptr. Floating point single precision.

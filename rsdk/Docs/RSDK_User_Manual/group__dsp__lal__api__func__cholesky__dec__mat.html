Cholesky decomposition of a matrix - LL - complex single precision.

The function applies Cholesky decomposition on complex input matrix and returns lower triangular matrix implementing the Cholesky-Crout algorithm.
Function assumes the input matrix is square and Hermitian.
Function should not be used for input matrices that are not positive definite or semi-definite.
Decomposition is unique when the input matrix is positive definite, then the output matrix has real and positive diagonal entries.
If the input matrix is positive semi-definite the decomposition is not unique and the output diagonal entries can be zeros.
input = L * L^H

Parameters
[out]pOutputResult contains 8 parallel low-triangular real matrices, size NxN.
[in]pInputOperand contains 8 parallel real matrices, size NxN.
[in]sizeNumber of rows and columns in the input and output matrices.
Note
Cholesky(inmatrix) = outmatrix with inmatrix = outmatrix*outmatrix^H
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [2..45]

Cholesky decomposition of a matrix - LL - real single precision.

The function applies Cholesky decomposition on real input matrix and returns lower triangular matrix implementing the Cholesky-Crout algorithm.
Function assumes the input matrix is square and symmetric.
Function should not be used for input matrices that are not positive definite or semi-definite.
Decomposition is unique when the input matrix is positive definite and the output matrix has real and positive diagonal entries.
If the input matrix is positive semi-definite the decomposition is not unique and the output diagonal entries can be zeros.
input = L * L^T

[out]pOutputResult contains 8 parallel low-triangular real matrices, size NxN.
[in]pInputOperand contains 8 parallel real matrices, size NxN.
[in]sizeNumber of rows and columns in the input and output matrices.
Note
Cholesky(inmatrix) = outmatrix with inmatrix = outmatrix*outmatrix^T
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.

Max - real single precision.

Function implements maximum operation for real data vectors.
The function returns the index of the maximum value.
In case of multiple appearances of the maximum value, the index of the first apperance is returned. Output must not be in-place memory.

Parameters
[out]pOutputResult contains a pointer to 8 parallel scalar values, the positions of the maximum values.
[in]pInputFirst operand contains 8 parallel real vectors, size N.
[in]sizeSize of input vector, N.
Note
max(vector) = scalar
The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 8000.

Max - complex single precision.

Eigen solver for complex upper Hessenberg form NxN matrices using Francis Algorithm - complex single precision.

Functions computes the eigenvalues and eigenvectors for the input matrices.
The eigen-decomposition is done executing Francis QR iterations.
A QR iteration step is performed with implicit shifts.
The function assumes the the matrices are in upper Hessenberg form.
The eigen vector in column k of the matrix V has the corresponding eigenvalue in the element k of the vector D.
Typically only 3*N iterations are required but the cautious limit is 30*N.
Function is restricted to matrices with values < 1e+18 due to overflows.
Output cannot be in-place memory.

Parameters
[out]pOutputDResult contains the 8 parallel D complex vectors, representing the eigenvalues - size 1xN.
[out]pOutputVResult contains the 8 parallel V complex matrices, representing the eigenvectors - size NxN.
[in]pInputOperand contains the 8 parallel complex matrices - size NxN.
[in,out]iterationsMaximum number of iterations to be applied to the input matrix.
At the end of the algorithm it will contain the number of iterations remaining.
[in]sizeNumber of rows and columns of input and V matrices and D vectors: N (N>=2).
Note
eig(matrix) = vector(eigenvalues) matrix(eigenvectors)
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N < 45.

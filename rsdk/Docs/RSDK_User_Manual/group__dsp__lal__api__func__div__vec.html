Vector division - complex single precision.

Function performs division of 2 complex data vectors.

Parameters
[out]pOutputResult contains 8 parallel complex vectors, size N.
[in]pInput1First operand contains 8 parallel complex vectors, size N.
[in]pInput2Second operand contains 8 parallel complex vectors, size N.
[in]sizeSize of input and output vectors, N.
Note
div(vector1, vector2) = vector1 ./ vector2
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [1..1365]

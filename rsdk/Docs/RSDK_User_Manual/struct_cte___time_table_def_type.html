Detailed Description

Structure for CTE time table definition.

This is a structure for only one table. If two tables are used, two structures must be defined.

Field Documentation

◆ eventsPtr

Cte_TimingEventType* eventsPtr

Pointer to the events list, which must have the tableLength corrected defined events, or an error will be reported. A NULL value for pEventActions before the tableLength limit will be used as a pEvents limit and the TableLength will be truncated to the counted number, with no errors. This means is possible to use a big number for tableLength and define the table end using a NULL pointer for pEventActions.

◆ tableLength

uint8 tableLength

The number of defined events to be used/added. It must be up to 32 for two tables usage and up to 64 if single table used. A zero length means the table is not well defined and an error will be returned.

◆ tableTimeExecLimit

uint32 tableTimeExecLimit

The limited time for table processing, in ns. 0 means no table end on time limit.

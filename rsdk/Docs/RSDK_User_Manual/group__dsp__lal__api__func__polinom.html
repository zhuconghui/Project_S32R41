Polynoms evaluation(the 8 polynoms are defined by 8 parallel streams of real coeficient vectors, size N+1) for 8 corresponding variable's values - real single precision.

The function evaluates the polynomial functions for a real value of the variable.
Each polynomial function is defined by the vector of the real values of the coeficients arranged in descending order.
The polynoms have the same degree, N.

Parameters
[out]pOutputResult contains the 8 parallel evaluation results P(x), real scalars.
[in]pInput1First operand contains 8 parallel real coeficients' vectors, size N+1.
[in]pInput2Second operand contains 8 real scalar variables.
[in]degreeThe polinomyals' degree, N.
Note
The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 8000.

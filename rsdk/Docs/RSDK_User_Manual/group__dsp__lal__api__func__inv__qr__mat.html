Matrix inverse - complex single precision.

Function implements matrix inverse using QR decomposition with Householder reflection.
Function multiplies the inverse of R matrix with the inverse of the Q matrix.
Function assumes input matrix is non-singular and has inverse.
Output can be in-place memory.

Parameters
[out]pOutputResult contains 8 parallel complex matrices,size NxN
[in]pInputOperand contains 8 parallel complex matrices, size NxN.
[in,out]pBuffer1Scratch area for 8 parallel complex matrices used for Q matrices, size N*N.
[in,out]pBuffer2Scratch area for 8 parallel complex matrices used for R matrices and R inverse matrices, size N*N.
[in]sizeNumber of rows and columns in the input and output matrices, N(>=2).
Note
inv(matrix) = matrix
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N < 32.

◆ rfeMainFsm()

rfeSwMainFsm_mainState_t rfeMainFsm ( rfeSwMainFsm_mainState_t  state,
rfe_error_t *  rfe___error___pointer 
)

This function performs the main finite-state-machine.

This function shall be called by the RFE abstraction 2 main app. This function will perform all needed function on the TEF82xx frontend.

Precondition
Call rfeSetSharedAdresses for shared memory addresses settings. Call rfeSetFrontendsConfiguration or default will be used rfeFrontEnd_Cascaded_e with RFE_MAX_SUPPORTED_DEVICES
Parameters
[in]state- Start state or the state at which to continue.
[in,out]rfe___error___pointer- Error handling parameter.
Returns
rfeSwMainFsm_mainState_t - The next state. This return value can be used as argument to the next invocation of this function. In this way we can step through the state machine, state by state.
Postcondition
NIL

◆ rfeSetFrontendsConfiguration()

void rfeSetFrontendsConfiguration ( rfeFrontEnd_Configuration_t  feConfigType,
uint8_t  numConnectedFrrontends,
rfe_error_t *  rfe___error___pointer 
)

This function set the number of connected frontends and the configuration used.

This function must be called before the start of the main fsm, before the TEF82xx init. Default configuration is rfeFrontEnd_Cascaded_e with RFE_MAX_SUPPORTED_DEVICES. Note that single mode on multiple TEF82xx is not supported e.g. rfeFrontEnd_Single_e with NUM_FRONTENDS_MAX

Precondition
NIL
Parameters
[in]feConfigType- Frontend configuration type.
[in]numConnectedFrrontends- Number of frontends that are connected to the SOC.
[in,out]rfe___error___pointer- Error handling parameter.
Postcondition
NIL

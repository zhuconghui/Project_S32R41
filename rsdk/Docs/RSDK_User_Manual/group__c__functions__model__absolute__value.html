Element-wise absolute squared value of a complex vector - single precision.

Calculate the absolute value also known as complex norm,
modulus, or magnitude of all input elements.
Input vector is assumed padded to the nearest memory line.
Output vector is real, with positive values (sign ignored).
output[k] = input.re[k]*input.re[k] + input.im[k]*input.im[k]

Parameters
[out]pOutputOutput real vector ptr.
[in]pInputInput complex vector ptr.
[in]sizeLength of pInput (useful length).
Returns
void
Note
abs2 (vector) = vector
v = n, a1.re, a1.im, ..., an.re, an.im;
abs2 (v) = n, ((a1.re^2)+(a1.im^2)), ..., ((an.re^2)+(an.im^2)); ;

Element-wise vector absolute value of a real vector - single precision.

Calculate the absolute value of all elements in input vector.
Input vector is assumed padded to the nearest memory line.
All output elements are positive (sign ignored).
output[k] = |input[k]|

Parameters
[out]pOutputOutput real vector ptr.
[in]pInputInput real vector ptr.
[in]sizeNumber of elements in vector, interval [0..65535].
Returns
void
Note
abs (vector) = vector
v = n, a1, a2, ..., an;
abs (v) = n, |a1|, |a2|, ..., |an|;

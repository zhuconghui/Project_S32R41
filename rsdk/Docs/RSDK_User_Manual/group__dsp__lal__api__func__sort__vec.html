Element-wise compare and compute minimum and maximum values - real single precision.

Compare each element from the first input vector with the element
at the same position from the second input vector, minimum result is copied in first output vector and
maximum is copied in second output vector.
Output must not be in-place memory vector.

Parameters
[out]pOutput1Result contains 8 parallel real vectors, representing the minimum values, size N.
[out]pOutput2Result contains 8 parallel real vectors, representing the maximum values, size N.
[in]pInput1Operand contains 8 parallel real vectors, size N.
[in]pInput2Operand contains 8 parallel real vectors, size N.
[in]sizeSize of input and output vectors, N.
Note
minMax (vector, vector) = (vector, vector)
v1 = a1, a2..., an;
v2 = b1, b2..., bn;
minMax1 (v1,v2) = (min (a1,b1), ..., min (an,bn);
minMax2 (v1,v2) = (max (a1,b1), ..., max (an,bn);
minMax = (minMax1, minMax2) The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 2000.

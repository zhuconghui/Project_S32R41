uint32_t  size 
)

Sum of all reciprocal vector elements - complex single precision.

Reciprocal summation is the addition of a sequence of each 1 divided by element in vector, called addends or summands. The result is their reciprocal sum or reciprocal total.

Parameters
[out]pOutputResult, contains a pointer to 8 parallel scalar complex values.
[in]pInputOperand, contains 8 parallel complex vectors, size N.
[in]sizeNumber of vector elements(N).
Note
element reciprocal sum (vector) = scalar
n = size
v = n, a1, a2..., an;
a1 = x + iy;
ersum(v) = 1/a1 + 1/a2 + ... + 1/an;
1/a1 = x/(x^2 + y^2) - iy/(x^2 + y^2); The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 8000.

Sum of all reciprocal vector elements - real single precision.

Reciprocal summation is the addition of a sequence of each 1 divided by element in vector, called addends or summands. The result is their reciprocal sum or reciprocal total.
The parallel stream result is NAN, if one input in that stream is zero.

Parameters
[out]pOutputResult, contains a pointer to 8 parallel scalar real values.
[in]pInputOperand, contains 8 parallel real vectors, size N.
[in]sizeNumber of vector elements(N).
Note
element reciprocal sum (vector) = scalar
n = size
v = n, a1, a2..., an;
ersum(v) = 1/a1 + 1/a2 + ... + 1/an; The maximum vector size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N <= 8000.

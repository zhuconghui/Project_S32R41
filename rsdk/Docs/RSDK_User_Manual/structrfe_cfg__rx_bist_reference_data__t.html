Detailed Description

Struct to hold value of RX Bist reference data.

refMag - Array of reference signal magnitudes difference vs 1st RX for all RX channels measured in [dB] for LNA and mixer input. refPh - Array of reference signal phase difference vs 1st RX for all RX channels measured in [rad] for LNA and mixer input.

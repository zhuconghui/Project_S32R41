Element-wise vector reverse cosine divided by PI, acos/PI or arccos/PI.

Calculate the acos of all 256 elements of input then normalize the output by pi.
acos returns an angle between -pi and pi and normalized with PI to get output limits to -1 to +1
output[k] = arccos(input[k]) / pi

Parameters
[out]pOutputOutput vector ptr.
[in]pInputInput vector ptr.
Returns
void
Note
arccos (vector) = vector
v = a1, a2, ..., a256;
arccos (v) = acos(a1)/pi, acos(a2)/pi, ..., acos(a256)/pi;

Element-wise vector arctangent2 divided by PI, atan2/PI or arctan2/PI.

Calculate the arctangent of the element-wise ratio pInputY/pInputX then normalize the output by pi.
Atan2 returns an angle between -pi and pi and normalized with PI to get output limits to -1 to +1
output[k] = arctan2(inputY[k], inputX[k])/pi = arctan(inputY[k]/inputX[k])/pi

Parameters
[out]pOutputOutput vector ptr.
[in]pInputYInput vector ptr.
[in]pInputXInput vector ptr.
[in]sizeNumber of elements in vector, interval [1..65535].
Returns
void
Note
arc-tangent2 (vector, vector) = vector
Y = n, y1, y2, ..., yn;
X = n, x1, x2, ..., xn;
arc-tangent2 (Y,X) = n, atan2(y1,x1)/pi, atan2(y2,x2)/pi, ..., atan2(yn,xn)/pi;
This is equivalent with:
arc-tangent (Y./X) = n, atan(y1/x1)/pi, atan(y2/x2)/pi, ..., atan(yn/xn)/pi;

Arccosine - real single precision, high accuracy.

Function calculates the inverse cosine of a real data vectors.
It returns arccos(x) in domain [0,pi] for x in domain [-1,1].
Computed using formula acos(x) = pi/2 - asin(x).
Output must not be in-place memory vector.

Parameters
[out]pOutputResult contains 8 parallel real vectors, size N.
[in]pInputOperand contains 8 parallel real vectors, size N.
[in]sizeSize of input and output vectors, N.
Note
acos(vector) = vector
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size range is [1..4095]

Arctangent - real single precision, high accuracy.

Function calculates the inverse tangent of a real data vectors.
It returns atan(x) in domain [-pi/2,pi/2] for x in domain (-INF,INF) using a Maclaurin expansion.
This avoids the expensive division needed in the Pade approximation alternative and is slightly faster.
Output must not be in-place memory vector.

[out]pOutputResult contains 8 parallel real vectors, size N.
[in]pInputOperand contains 8 parallel real vectors, size N.
[in]sizeSize of input and output vectors, N.

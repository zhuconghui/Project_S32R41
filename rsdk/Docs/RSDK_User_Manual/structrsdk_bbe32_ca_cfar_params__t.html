Detailed Description

The data types accepted by the BBE32 algos.

Parameters for BBE32 radar signal processing algorithms.

Field Documentation

◆ dopplerBins

uint16_t dopplerBins

[in] Number of doppler bins. Must be multiple of 16

◆ guardInterval

uint8_t guardInterval

◆ pDetectBitmap

uint32_t pDetectBitmap

[out] Pointer to data buffer which will store peak detection bitmap results, of size [(N_CHIRPS/16)*N_SAMPLES] It is represented as uint32_t to allow passing 32-bit addresses from A53 to BBE32

◆ pRdm

uint32_t pRdm

[in] Pointer to data buffer containing 2-D range-doppler magnitude matrix of size [N_CHIRPS*N_SAMPLES]. It is represented as uint32_t to allow passing 32-bit addresses from A53 to BBE32. The buffer must be aligned at 32 bytes and size must be multiple of 32 bytes (16 16-bit magnitude values)

◆ pThr

uint32_t pThr

[in] Pointer to scratch buffer used by RsdkBbe32Cfar() to store computed threshold values It is represented as uint32_t to allow passing 32-bit addresses from A53 to BBE32. The buffer must be aligned at 32 bytes and size must be multiple of 32 bytes

◆ rangeBins

uint16_t rangeBins

[in] Number of range bins.

◆ thresholdFactor

uint16_t thresholdFactor

[in] Threshold factor. SPT Mag2Log2 format. User must prevent overflow/saturation.

◆ windowSize

uint8_t windowSize

[in] Window size for CFAR algo.

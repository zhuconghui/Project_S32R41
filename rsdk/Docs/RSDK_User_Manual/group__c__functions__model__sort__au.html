Odd Even transposition sort real elements.

Odd-Even Sort / Brick Sort of all 16 vector real elements.

Parameters
[out]pOutputOutput float32 vector ptr.
[in]pInputInput float32 vector ptr.
Returns
void
Note
Odd-Even Transpose Sort (vector) = vector
v = 16, a1, a2..., a16;
OETS (v) = sorted(v);
k = n/2
Step 0 -> re arrange data
a[1], 0, a[3], 0, a[5], 0, ... a[2k-1], 0
a[2], 0, a[4], 0, a[6], 0, ... a[2k], 0
Step 1
MAX(a[1],a[2]), 0, MAX(a[3],a[4]), 0, MAX(a[5],a[6]), 0, ... , MAX(a[2k-1],a[2k]), 0
MIN(a[1],a[2]), 0, MIN(a[3],a[4]), 0, MIN(a[5],a[6]), 0, ... , MIN(a[2k-1],a[2k]), 0

MAX(a1,a2) = (a1+a2)/2 + |a1-a2|/2
MIN(a1,a2) = (a1+a2)/2 - |a1-a2|/2

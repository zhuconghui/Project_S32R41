void __stdcall C_MODEL_DLL Rsdk_SP_bflyDif2_Vo1024f32cVi1024f32c ( rsdk_complex_float32_t *  pOutput,
rsdk_complex_float32_t const *  pInput 
)

1D FFT DIF Fast Fourier transform vector complex elements, output is BR ordered.

FFT vector 1024 complex elements without bit reverse index change.
Decimation in frequency approach, radix 2.
Input is linear ordered, output is bit reverse ordered.
For re-order use Rsdk_SP_bitRev_Vo1024f32cVi1024f32c.
For zero padding use Rsdk_SP_zeroTrail_Vof32cVif32c.

Parameters
[out]pOutputOutput vector ptr.
[in]pInputInput vector ptr.
Returns
void
Note
Fast Fourier transform fft_fd (vector) = vector
v = a0000000000, a0000000001, ..., a1111111111;
u0000000000 = sum ( v(n)*exp(-j*2*pi* 0*(n-1)/1024) ), n = 1 ... 1024
u1000000000 = sum ( v(n)*exp(-j*2*pi* 1*(n-1)/1024) ), n = 1 ... 1024

u1111111111 = sum ( v(n)*exp(-j*2*pi*1023*(n-1)/1024) ), n = 1 ... 1024
fft_fd(v) = u

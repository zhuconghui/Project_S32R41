Split a complex matrix into two matrices first containing the real complex part and second the imaginary complex part - single precision.

Break input complex matrix in two output matrices containing real part and imaginary part.
First output matrix holds the real part of the complex input matrix.
Second output matrix holds the imaginary part of the complex input matrix.
This is the reverse function to Rsdk_DT_interl_Mof32cp8Mif32p8Mif32p8.
Output must not be in-place memory.

Parameters
[out]pOutput1First result real matrix size NxM..
[out]pOutput2Second result real matrix size NxM.
[in]pInputOperand complex matrix size NxM.
[in]rowsNumber of rows in input, output matrixes N.
[in]colsNumber of columns in input, output matrixes M.
Note
deinterl(complex_matrix) = (real_matrix, real_matrix)
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: NxM <= 2000.

Join two matrices with real elements into a matrix with complex elements - single precision.

Interleave first matrix as real parts of the corresponding output complex elements and second matrix as the imaginary parts, respectively.
First input matrix holds the real part of the complex output matrix.
Second input matrix holds the imaginary part of the complex output matrix.
This is the reverse function to Rsdk_DT_deinterl_Mof32p8Mof32p8Mif32cp8.
Output must not be in-place memory.

Parameters
[out]pOutputResult complex matrix size NxM.
[in]pInput1First operand real matrix size NxM.
[in]pInput2Second operand real matrix size NxM.
[in]rowsNumber of rows in input, output matrixes N.
[in]colsNumber of columns in input, output matrixes M.
Note
interl(real_matrix, real_matrix) = complex_matrix
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: NxM <= 2000.

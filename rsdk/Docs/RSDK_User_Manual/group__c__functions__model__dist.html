Squared Mahalanobis distance between two random vectors with 2 variables.

Compute squared Mahalanobis distance between two vectors of the same distribution with the inverse covariance matrix S pre-calculated.
Input1 vector contains n (size1) observations in pairs, for 2 variables.
Input2 vector contains m (size2) observations in pairs, for 2 variables.
Input3 vector contains pre-calculated inverse covariance matrix S as a vector s11, s22, 2*s12.
Input vector sizes are is n x 2, m x 2 and 3 float SP elements.
Output vector contains squared distances from first to second vector.
Output vector size is n x m float SP elements.
Output vector is padded to NUM_AU with zeros n x NUM_AU.

Parameters
[out]pOutputOutput vector.
[in]pInput1First input vector pairs ptr.
[in]pInput2Second input vector pairs ptr.
[in]pCovInverse Covariance vector ptr, size 3.
[in]size1Number of pairs in first vector, interval [1..65535].
[in]size2Number of pairs in second vector, interval [1..65535].
Returns
void
Note
mahal2 (vector, vector, vector) = vector
v1 = (x1, x2), (x3, x4), ..., (x2n-1, x2n);
size(v1) = 2n;
v2 = (y1, y2), (y3, y4), ..., (y2m-1, y2m);
size(v2) = 2m;
v3 = c11, c22, 2*c12;
size(v3) = 3;
v4 = dij
size(v4) = n * m;
dij = d((xi, xi+1), (yj, yj+1)) = (xi-yj)^2 * c11 + (xi+1-yj+1)^2 * c22
  • (xi-yj)*(xi+1-yj+1) * 2*c12,
    mahal2 (v1,v2,v3) = d11, d12, ..., d1m, d21, d22, ..., d2m, ... dn1, dn2, ..., dnm,

Std_ReturnType Dsphd_CreateJobList ( Dsphd_JobType *  jobPtr,
uint8 *  jobPtrListBuffer,
uint16  numJobs,
uint8_t  isCrcEnabled 
)

Creates a list of jobs formatted for the DSP Dispatcher.

It reads the job information from a user-defined list, copies it to a shared buffer and computes CRC for each entry.

Parameters
[in]jobPtrList of jobs to be sent to the Dispatcher
[in]jobPtrListBufferPointer to a buffer of size DSPHD_SIZEOF_JOB_LIST that must be allocated by the user in a shared memory area, which is accessible to the BBE32 DSP.
[in]numJobNumber of jobs in the user-defined list
[in]isCrcEnabledCRC check on/off for the jobs (0/other values but 1 = OFF, 1 = ON)
Returns
RSDK_SUCCESS or a specific error code.
Precondition
It should be called whenever the user wishes to change the list of periodic jobs running on the DSP. Calling this function alone does not change the DSP function schedule, it must be followed by another call to Dsphd_SendMsg(), using either the DSPHD_MSG_UPDATE_RC_JOB_LIST or DSPHD_MSG_UPDATE_LONG_JOB_LIST message types.

Std_ReturnType Dsphd_SendMsg ( Dsphd_MsgTypeType  msgType,
uint32  msgPayload 
)

Sends a message to the BBE32 DSP Dispatcher .

The message follows a simple "type+payload" protocol

Parameters
[in]msgTypetype of message
[in]msgPayload32-bit information field which can contain a scalar or 32-bit pointer usable by the BBE32 DSP
Returns
RSDK_SUCCESS or a specific error code.
Precondition
For DSPHD_MSG_UPDATE_RC_JOB_LIST or DSPHD_MSG_UPDATE_LONG_JOB_LIST message types, the msgPayload must be a pointer to the pJobListBuffer initialized by Dsphd_CreateJobList()

Lower triangular matrix inverse - complex single precision.

Function implements matrix inverse for a lower triangular matrix.
Function assumes input matrix is a lower triangular, non-singular and has inverse.
Output can be in-place memory.

Parameters
[out]pOutputResult contains 8 parallel complex matrices,size NxN
[in]pInputOperand contains 8 parallel complex matrices, size NxN.
[in]sizeNumber of rows and columns in the input and output matrices, N(>=2).
Note
inv(matrix) = matrix
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: N < 45.

Lower triangular rectangular matrix inverse - complex single precision.

Function implements matrix inverse for a lower triangular rectangular matrix.
Function assumes input matrix is rectangular, lower triangular, non-singular and has inverse.
Function assumes output matrix is a NxM matrix filled with zeros.
Output cannot be in-place memory.
Number of rows of the input matrix should be <= number of columns

Parameters
[out]pOutputResult contains 8 parallel complex matrices,size NxM
[in]pInputOperand contains 8 parallel complex matrices, size MxN.
[in]rowsNumber of rows in the input matrix and number of columns in the output matrix, M(>=2), M<=N.
[in]colsNumber of columns in the input matrix and number of rows in the output matrix, N(>=2).
Returns
void
Note
inv(matrix) = matrix
The maximum matrix size is estimated in the ideal condition that the function use the whole memory of 256 kBytes: MxN < 46x46.

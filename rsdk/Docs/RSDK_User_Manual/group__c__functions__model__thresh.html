Return bitmask that encodes input vector variation against a threshold.

Bitmask encodes for each of the n input elements, if it's larger or smaller than the input threshold.

Parameters
[out]pOutputOutput unsigned int 32bit mask vector.
[in]pInput1Input real vector.
[in]pInput2Input real scalar.
[in]sizeLength of Input1 vector.
Returns
void
Note
thresh_bitmask(vector) = vector
thresh_bitmask(v) = [a0 a1 ... an], where
a0 = [b31 b30 ... b1 b0]
a1 = [b63 b62 ... b33 b32], etc
(a_x are floats, b_y are bits)

b_y = 0 if v_i <= threshold
b_y = 1 if v_i > threshold,
with y = i % 32 and i = x * 32 + y.

More intuitively, the resulting vector of bits corresponds to the signs of the reversed difference vector between the input vector (pInput1) and the threshold constant (pInput2).

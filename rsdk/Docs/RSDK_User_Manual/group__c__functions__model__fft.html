void __stdcall C_MODEL_DLL Rsdk_SP_zeroTrail_Vof32cVif32c ( rsdk_complex_float32_t *  pOutput,
rsdk_complex_float32_t const *  pInput,
uint32_t const  out_elem_cnt,
uint32_t const  in_elem_cnt 
)

Vector pad trailing zeros to n float32 complex elements.

Pad trailing zeros for an variable element input vector to n elements. Input vector element count should be between 1 to n-1 elements. Input and output can point to same address - inplace.

Parameters
[out]pOutputOutput vector ptr.
[in]pInputInput vector ptr.
[in]out_elem_cntOutput vector element count.
[in]in_elem_cntInput vector element count.
Returns
void
Note
Use before FFT if too few data points. vpt0 (vector) = scalar
v = a1, a2..., an; k=1..n-1
vpt0 (v) = a1, a2..., ak, 0, 0, 0, ...;

Cholesky decomposition for NxN matrix - complex hermitian single precision.

Applies Cholesky decomposition on positive definite hermitian input matrix and returns lower triangular matrix with positive real values on the main diagonal. Both the input and output matrices are assumed to be square. Size must not be smaller than 2.

Element-wise signal-to-noise ratio or SNR in dB.

Compute Signal to noise ratio of signal and noise real vectors.
output[k] = 10*log10(input1[k]/input2[k])

Parameters
[out]pOutputOutput vector ptr.
[in]pInput1Input vector ptr.
[in]pInput2Input vector ptr.
[in]sizeNumber of elements in vector, interval [1..65535].
Returns
void
Note
signal-to-noise ratio (vector, vector) = vector
v1 = n, a1, a2, ..., an;
v2 = n, b1, b2, ..., bn;
SNR (v1,v2) = n, 10*log10(a1/b1),... ,10*log10(an/bn);
= n, 10*log2(a1/b1)/log2(10),... ,10*log2(an/bn)/log2(10);
= n, 3.0103*log2(a1*rcp(b1)),... ,3.0103*log2(an*rcp(bn));

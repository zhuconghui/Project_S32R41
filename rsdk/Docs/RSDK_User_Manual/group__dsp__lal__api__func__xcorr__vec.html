Cross correlation on vectors - complex single precision.

Function implements cross correlation operation 2 complex data vectors.

Parameters
[out]pOutputResult contains 8 parallel complex vectors, size 2*max(M,N)-1.
[in]pInput1First operand contains 8 parallel complex vectors, size N.
[in]pInput2First operand contains 8 parallel complex vectors, size M.
[in]size1Size of input and output vectors, N.
[in]size2Size of input and output vectors, M.
Note
xcorr(vector1,vector2) = vector
The following sizes are estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
size1 range is [1..N]
size2 range is [1..M]
(N + M + 2 * max(M,N)) < 4096

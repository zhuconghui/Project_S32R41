QR decomposition of a matrix - complex single precision.

Function computes the QR decomposition in parallel for each complex matrix in batch using Householder reflection.
Function assumes that all matrices have linearly independent columns.
Usual R, Q are not unique, but if input matrix is of full rank, then there exists a single R that has all positive diagonal elements.
If input matrix is square non singular, then the decomposition is unique.
Corresponding rows and columns in Q and R can flip their signs.
pOutputR and pInput can point to the same address - inplace mode. In this case the input buffer is overwritten.
outputQ*outputR = input
Q*R = input

Parameters
[out]pOutputRFirst result contains 8 parallel complex R matrices, size MxN.
The R-matrix is an upper triangular matrix.
[out]pOutputQSecond result contains 8 parallel complex Q matrices, size MxM.
The Q-matrix has orthonormal columns(QH*Q=I). If input is a square
matrix Q is orthogonal(Q*QH=QH*Q=I).
[in,out]pBufferScratch area for a vector with the length equal with the number of
lines in the input matrix, size M.
[in]pInputOperand contains 8 parallel complex matrices, size MxN.
[in]rowsRow size of input matrix, Q matrix and R matrix and column size for Q matrix - (M).
[in]colsColumn size of input matrix and of R matrix - (N).
Note
qr(matrixM) = matrixQ, matrixR with M = Q*R
rows >= cols
The following size is estimated in the ideal condition that the function uses the whole memory of 256 KBytes.
If used in inplace mode:
rows range is [2..M]
cols range is [2..N]
(M * (N + M + 1)) < 4095
else:
rows range is [2..M]
cols range is [2..N]
(M * (2 * N + M + 1)) < 4095
